# 秋招职位筛选助手

基于 [mrcxsy/boss-auto-apply](https://github.com/mrcxsy/boss-auto-apply) 改造的 Chrome 扩展。手动启动一轮少量浏览，按薪资、城市、AI方向和秋招资格筛选，结合简历生成话术草稿，由本人审核发送。

原始需求见 [docs/原始需求.md](docs/原始需求.md)。

## 安装与使用

1. 在 Chrome 打开 `chrome://extensions`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本 README 所在目录（含 manifest.json）。无需构建或安装 npm 依赖。
3. 点击扩展图标，打开配置与候选清单，填写城市、最低月薪、毕业年份和方向。
4. 如需AI匹配，粘贴脱敏简历，选择 DeepSeek 或 OpenAI、填写模型名称及 API Key，阅读并勾选数据发送同意，再保存。Chrome 会请求所选模型域名权限。未配置AI时仍可浏览及规则筛选，结果标记待人工确认。
5. 手动登录 BOSS，打开职位搜索页 `/web/geek/jobs`，先使用官方搜索设置城市、校招条件和关键词。扩展不会自动改写官方搜索条件。
6. 在右下角助手点击“开始一轮”。完成后到配置与候选清单刷新、审核、编辑及复制话术，手动发送。

已有搜索页在安装或更新扩展后需要刷新。请勿同时运行原版投递插件。

## 浏览与暂停

- 默认每轮最多处理5条未浏览记录，详情访问间隔60秒，结束后休息30分钟，再手动启动下一轮。
- 每轮数量支持1—20条，访问间隔至少30秒，轮次间休息至少5分钟。这些是工程限制，不是平台认可的安全阈值。
- 一次只打开一个正常职位详情标签（后台标签），读取完成后关闭。不会点击沟通按钮，也不访问BOSS非公开接口。
- 当前列表无新职位时，等待后最多连续滚动两次；仍无新职位就结束。首版不自动翻页或切换搜索词。
- 暂停会取消详情或模型请求。被中断的详情记录保留为待确认；点击继续后处理下一条。读取失败的记录需要在结束后“移出记录”，才能下轮重新处理。
- 停止、验证码、限流、登录失效、详情重定向或JD无法读取都会结束本轮。轮次结束、刷新、浏览器重启均不自动恢复。
- 内部15秒心跳只维持Chrome扩展后台，不向BOSS发送请求。后台状态丢失时停止，启动时清理由扩展登记的遗留详情标签。

低频自动浏览仍可能触发账号限制。首版只完成离线模拟页面验证，未在真实BOSS账号实测，不承诺免封号。

## 筛选规则

- 最低月薪按区间下限判断：门槛25K时，25—40K通过；15—30K待确认；15—24K跳过。
- 面议、乱码、缺失、年包、日薪或单位不明均保留待确认，不默认达标。仅有明确薪资月数才计算年包。
- 方向关键词支持逗号分隔，英文大小写不敏感；区分Agent／大模型应用与算法／训练方向。优先方向未明确匹配时列为待确认。
- 明确不接受应届生或要求工作年限且未说明接受应届的职位跳过。毕业年份、校招资格不明确则待确认。
- 规则只能辅助筛选；JD中的否定、范围或复杂资格需要人工核对。岗位链接去掉追踪参数作为去重键。
- AI返回不匹配时不生成话术；调用失败会显示错误，不使用通用兜底话术。

## 数据与权限

只默认申请本机存储和 BOSS 域名权限。外部模型域名在配置页显式授权，接口固定为所选服务的官方域名。

本地保存配置、简历、记录和API Key；Chrome扩展存储未加密。模型调用只发送配置页列出的脱敏简历、JD及少量岗位与求职字段，不转发BOSS Cookie或登录凭证。自动脱敏仅覆盖手机号和邮箱；姓名、住址等请手动去除。模型输出请核对真实性。

记录可导出为JSON，导出不包含API Key或完整简历。导出文件包含职位、JD及话术，分享前请自行检查。

## 开发与验证

运行纯函数、后台流程测试及语法检查无需安装依赖：

```sh
npm test
npm run check
```

浏览器模拟测试使用单独的 Chrome 上下文，所有页面请求均拦截为本地fixture，不登录BOSS、不调用真实模型：

```sh
npm ci
npm run test:browser
```

默认使用本机 Google Chrome；可设置 `CHROME_CHANNEL=chromium` 并先运行 `npx playwright install chromium`。预览截图输出到 `artifacts/`。
