# 秋招职位筛选助手

面向 BOSS 直聘的 Chrome 扩展，帮助求职者筛选职位、匹配简历，并生成个性化打招呼草稿，由本人审核发送。

## 核心功能

- 按薪资、城市、AI／Agent／算法方向和秋招资格筛选职位。
- 结合简历与 JD 分析匹配理由、经历缺口和待确认事项。
- 生成个性化话术，支持编辑、保存和复制。
- 少量、低频浏览，支持暂停、停止和异常中止。
- 本地保存与去重职位记录，支持导出候选清单。

## 安装

将 [安装指南](docs/安装指南.md) 交给 AI 助手，按文档完成安装与配置。
