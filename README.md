# 秋招职位筛选助手

面向 BOSS 直聘的 Chrome 扩展，帮助求职者筛选职位、匹配简历，并生成个性化打招呼草稿，由本人审核发送。

![项目概念图：低频浏览、职位筛选、简历匹配、话术草稿与本人审核发送，旨在降低账号风控与封号风险](docs/images/project-concept.png)

## 核心功能

- 按薪资、城市、AI／Agent／算法方向和秋招资格筛选职位。
- 导入本地简历 JSON，结合 JD 分析匹配理由、经历缺口和待确认事项。
- 遇到候选停在 JD，话术经本人修改确认后，在关闭平台自动招呼的新会话中作为首次招呼发送。
- 脚本自动低频查找，未命中时休息后继续；支持暂停、停止和异常中止。
- 本地保存职位与话术修改记录，可导出用于后期调优提示词。

## 安装

将 [安装指南](docs/安装指南.md) 交给 AI 助手，按文档完成安装与配置。
