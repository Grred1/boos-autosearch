# 安装指南

可将本文交给 AI 助手执行。扩展无需构建，日常使用不需要安装 Node.js 或 npm 依赖。

## 给 AI 助手的安装任务

> 帮我安装 https://github.com/Grred1/boos-autosearch 的 Chrome 扩展。先检查本地是否已有项目；已有则复用，不覆盖未提交修改，没有则克隆到我指定的目录。确认目录包含 manifest.json 后，指导我在 Chrome 中加载扩展，完成求职条件和模型配置。不要自动登录招聘账号、发送消息或上传简历，不要把 API Key 写入项目文件。所有文件集中放在项目目录，不留下项目外临时副本。

## 获取项目

```sh
git clone https://github.com/Grred1/boos-autosearch.git
```

也可以从仓库的 Code 菜单下载 ZIP，解压后使用。

## 加载扩展

1. 在 Chrome 打开 `chrome://extensions`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的项目目录。
3. 点击扩展图标，打开“配置与候选清单”。

安装或更新后，已有的 BOSS 搜索页、JD及聊天页需要刷新。请勿同时运行原版自动投递插件。

## 配置求职条件与模型

填写目标城市、最低月薪、毕业年份、岗位方向和浏览节奏，保存配置。

使用 config/resume.example.json 创建本地简历模板，填写完整 resumeText 或各分区文本，保存到被 Git 忽略的 local/resume.json。在配置页选择“导入本地简历 JSON”，检查文本后保存。空白模板会被拒绝。

macOS 可用 scripts/extract-resume.swift 在本机对 PDF 进行 OCR，图片仅在内存处理，输出限制在 local/ 目录。提取结果需要本人核对；不需要将 PDF 复制到仓库。

需要 AI 匹配与话术时，选择 DeepSeek 或 OpenAI，填写模型名称和 API Key。阅读并勾选数据发送同意后保存，再授权所选模型域名。API Key 应由本人在扩展配置页填写。未启用 AI 时仍可浏览和执行规则筛选，结果待人工确认。

配置、简历、记录和 API Key 保存在本机扩展存储中，未加密。模型调用会向所选服务发送配置页列出的简历、JD及岗位和求职字段，不转发 BOSS Cookie。默认发送前移除简历中的手机号和邮箱；关闭该选项后将发送完整简历文本，需重新同意数据发送。Git 忽略只防止常规提交，不阻止你手动上传私人文件。

提交前运行 `node scripts/check-public-files.cjs`，检查已暂存的文件路径、疑似Key和本地简历中的姓名及联系方式。可在本机 pre-commit hook 中调用该脚本；这不能代替人工审核。Key仅填写在扩展配置页，不放进简历JSON。

## 开始使用

1. 本人登录 BOSS，在职位搜索页 `/web/geek/jobs` 设置官方搜索条件。
2. 点击右下角助手的“开始一轮”。默认每轮最多处理5条，详情访问间隔60秒，轮次结束后休息30分钟，再手动启动下一轮。
3. 默认开启“遇到候选或待确认职位就停在JD等待审核”：保留同一个详情标签并停止本轮浏览，在JD侧边显示分析和可编辑话术。
4. 修改话术可填写原因并保存。本机记录模型原稿、每次修改前后文本、对应JD及模型/提示词版本，供以后调优；不会自动上传或训练。
5. 核对职位和最终话术后，阅读并勾选确认，再点击“确认本职位并沟通发送”。助手只对这一个职位执行一次沟通和发送。BOSS点击“立即沟通”可能先发平台默认招呼并展示在线简历，然后才发送自定义话术。
6. 聊天顶部必须能核实原JD链接和招聘者，否则停止。发送结果不明时不重试，手动核对BOSS后刷新JD，选择“我已核对BOSS，结束本条审核”。本条保持锁定，其他职位可在休息结束后继续浏览。
7. 不打算沟通可选“本条暂不沟通”。审核完成后回到搜索页，满足冷却后手动开始下一轮。

暂停会取消当前请求，继续后处理下一条；需要重新处理被中断的职位，可在结束后将其移出记录。遇到验证、限流、登录失效或详情异常时，本轮会停止。

低频自动浏览仍可能触发账号限制，不承诺免封号。已完成真实职位读取、模型生成及JD审核面板验证；新版确认后发送尚待本人批准真实话术后实测。模型生成的话术需要核对真实经历。已保存的JD可点击“重新分析已保存JD”，不会再次访问BOSS；公司字段可先核对修正。

“导出话术修改记录”仅在本人点击时下载JSON；若放进项目，请保存到被忽略的 local/ 中。记录可能包含话术中的个人信息，不要公开提交。详细行为见[逐条审核与发送](逐条审核与发送.md)。

## 常见问题

- **没有出现助手**：确认扩展已启用，页面是 BOSS 职位搜索页，并刷新页面。
- **无法开始新一轮**：查看是否处于轮次间休息、已有轮次运行或有JD等待审核；先完成审核，再等待休息结束。
- **模型调用失败**：检查域名授权、API Key、模型名称和数据发送同意；失败时不会生成通用兜底话术。
- **没有候选结果**：检查薪资、关键词、城市和毕业年份配置，并查看“待确认”与“已跳过”记录。
